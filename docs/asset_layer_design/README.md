# 资产层架构整理

本目录用于讨论新的资产层逻辑。这里的文档先作为设计草案，不直接代表已落地的生产协议。

## 目标

- 明确 LLM 不承担长期记忆，所有可复用资料必须写入本地数据。
- 区分普通资产、地图、CG、线索、渲染产物，避免用一个字段混管全部展示逻辑。
- 先整理协议边界，再统一迁移后台测试、前台展示和导演层 prompt。

## 当前结论

- 右侧资产夹不是资产总账，只是一个前台展示视图。
- `item` 是玩家持有、可装备、可消耗物。
- `prop` 是场景线索、机关器物、不可携带或未归属物。
- `clue` 不进入资产夹，先进入线索层，确认后再提升为资产。
- `map` 和 `cg` 都可被资产系统引用，但不和普通资产同一套管理逻辑。
