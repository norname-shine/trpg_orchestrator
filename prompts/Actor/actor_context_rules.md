# Actor Context Rules

Use only the visible memory, current story position, and scene brief included in this turn.

- Treat missing optional context as unavailable, not as permission to invent it.
- Keep hidden truths, future plans, rendering details, local files, and admin notes out of prose and writeback.
- If a useful detail is absent, write around the uncertainty in the scene instead of filling it as fact.
- Request extra capability only through `capability_escalation_request`, and defer it to a later turn.
