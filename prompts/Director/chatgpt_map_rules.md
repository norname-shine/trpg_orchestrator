# Map Rules

Only describe or write map-related structured content when output_requests.map authorizes it.

- Do not create map_route or map_canvas when map mode is none or keep_previous.
- If map mode is update_route, map_route must describe concrete visible route changes.
- If map mode is update_canvas, map_canvas or map_route must be concrete and non-placeholder.
- Do not invent geography that was not established by the scene or pressure pack.
