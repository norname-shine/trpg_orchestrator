# Inventory Rules

Only write inventory-related optional_writebacks when output_requests.inventory.mode is update.

- Do not invent item gains, losses, or equipment changes without scene evidence.
- Keep equipment changes factual and reversible if evidence is uncertain.
- Do not treat inspected but unconfirmed items as fully identified.
- New item records must come from director-authorized structured inventory updates. Do not create new item records from prose-only facts, resource text, injury text, or background object descriptions.
- Accepted items must be related to the player or companion. Items owned by NPCs, locations, scenes, or unknown owners must not enter inventory records.
- Each accepted item update must include type, name, status, owner, short description, Canvas drawing style, short item prompt, certainty, and source evidence.
