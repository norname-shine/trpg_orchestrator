# Prompt Rules Index

This is the master index for the prompt package. Runtime prompt files are organized by layer; machine routing remains in `prompt_modules.json`.

## Directory Layout

- `ReferenceSpec/`: reference and citation standards for prompt files.
- `Director/`: director-layer rules for pressure packs, macro pacing, payload intent, and control decisions.
- `Actor/`: actor-layer rules for prose, dialogue, visible checks, image pass prompts, and evidence candidates.
- `Backend/`: local engineering, frontend, encoding, persistence, cache, and QA rules.
- `Hotload/`: lazy-loading, output-contract, pruning archive, and runtime injection support.

## Runtime References

- `prompt_modules.json`: hotload registry. Module `path` values are relative to `prompts/`.
- `prompt_language_sync.json`: bilingual sync baseline generated by `sync-prompts --apply`.
- `prompt_rules_index.json`: machine-readable mirror of this index.
- `ReferenceSpec/reference_protocol.md`: citation and update rules for prompt references.

## Director Layer

The director layer decides pressure, pacing, boundaries, payload requests, and state hints. See `Director/INDEX.md`.

- Core prompt: `Director/v4_director_prompt.md`.
- Context and pass prompts: `Director/v4_campaign_context_prompt.md`, `Director/v4_payload_fulfillment_prompt.md`, `Director/v4_light_action_rules.md`.
- Audit prompt: `Director/v4_audit_prompt.md`.
- Control modules: `Director/dice_check_rules.md`, `Director/inventory_rules.md`, `Director/dossier_rules.md`, `Director/chatgpt_map_rules.md`, `Director/visual_asset_protocol.md`, `Director/visual_contract_director_rules.md`.

## Actor Layer

The actor layer writes player-facing story JSON and separate actor image prompts. See `Actor/INDEX.md`.

- Core prompt: `Actor/chatgpt_host_prompt.md`.
- Always-on support: `Actor/actor_context_rules.md`, `Actor/actor_writeback_rules.md`.
- Actor-specific lazy modules: `Actor/actor_dice_check_rules.md`, `Actor/actor_inventory_rules.md`, `Actor/actor_dossier_rules.md`, `Actor/actor_map_rules.md`, `Actor/actor_character_evidence_rules.md`.
- Actor image pass: `Actor/chatgpt_image_rules.md`; text/story prompts do not receive visual payloads, while image prompts receive sanitized image instructions and visible scene context.

## Backend Layer

The backend layer maintains local orchestration, encoding, persistence, assets, frontend behavior, validation, and audit plumbing. See `Backend/INDEX.md`.

- Architecture and model boundaries: `Backend/codex_system_architecture_rules.md`, `Backend/model_layer_contract_rules.md`.
- Runtime safety and UX: `Backend/encoding_rules.md`, `Backend/frontend_interaction_rules.md`, `Backend/campaign_data_lifecycle_rules.md`.
- Assets and QA: `Backend/asset_cache_lifecycle_rules.md`, `Backend/visual_contract_lifecycle_rules.md`, `PromptModules/asset_output_rules.md`, `Backend/canvas_asset_generation_rules.md`, `Backend/gallery_asset_rules.md`, `Backend/ai_flavor_check_rules.md`.

## Hotload Layer

Hotload is the runtime selection and injection layer. See `Hotload/INDEX.md`.

- Director/audit control modules: `Hotload/lazy_context_rules.md`, `Hotload/output_contract_rules.md`.
- Actor pruning archive: `Hotload/actor_prompt_pruned_fields.md`.
- Actor prompts receive only compact visible capability summaries, current story position, scene brief, and allowed evidence/check areas.

## Bilingual Package Policy

- English runtime prompt files and `_CN.md` Chinese packages must be paired in the same directory.
- Run `python -m trpg_orchestrator.cli sync-prompts --apply` to refresh the sync baseline after prompt moves or edits.
- Run `python -m trpg_orchestrator.cli sync-prompts --check` before prompt changes are considered complete.
- The sync command guarantees pair coverage and one-sided-change detection; it does not guarantee translation quality.
