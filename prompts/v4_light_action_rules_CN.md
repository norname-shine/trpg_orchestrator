# V4 轻量操作规则

本规则只用于以下固定轻量玩家操作：

- 观察周围
- 与 NPC 对话
- 检查物品

这些操作允许直接生成可给前台展示的轻量 JSON 回复。复盘/回顾、继续不属于轻量操作，必须走正常文本回合路径。

## 输出风格

- 输出短、清楚、偏操作信息。
- 不写华丽文笔，不做长篇氛围铺陈，不写章节式正文。
- 优先给出具体发现、可用信息和玩家下一步可理解的提示。
- 只有当现场确实需要立即选择时，才输出 `choice_prompt`。
- 不揭露当前角色不该知道的隐藏真相。

## JSON 契约

只返回严格 JSON：

```json
{
  "blocks": [],
  "summary": "",
  "state_writeback": {}
}
```

该 JSON 必须兼容正常前台跑团记录解析：

- `blocks` 使用与演员层输出相同的 block schema。
- 合法 block `type` 只能是 `gm_narration`、`player_action`、`npc_dialogue`、`system_check`、`choice_prompt`，不要使用 `text`。
- `state_writeback` 使用与演员层输出相同的写回 schema。
- 写回保持最小化。如果轻量操作只是观察既有信息，可以返回空写回对象或无变化写回，不要制造新的长期事实。

## 边界

- 只有轻量操作确认真实变化时才更新状态。
- 本路径保持短、清楚、偏操作信息。
