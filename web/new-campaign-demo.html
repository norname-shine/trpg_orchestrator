    新建跑团

    初始化模型接入、故事篇幅、角色资料、属性、伙伴和当前跑团临时规则。这里只写入初始记忆，不触发正文生成。

    故事模板

    选择故事基础类型。模板会影响默认规则、属性命名和初始化记忆，但不会限制后续剧情。

    故事篇幅

    决定故事大致长度和进度规划。短篇更集中，中篇适合完整主线，长篇适合多章节展开。可以使用 AI 问答来补全故事设定；你回答得越具体，后续故事脉络越清晰。

    模型模式

    选择后台如何分工生成跑团内容。默认模式使用导演层规划剧情，演员层负责正文输出。

    API Key 明文不会写入 campaign_profile.json；后端只保存 api_key_ref 或空字符串。

    故事设定 / 开场 Prompt

    写下世界观、主角处境、开场钩子和不要过早揭露的内容。越具体，初始化记忆越稳定。

    角色卡 / 属性与背景

    记录主角的基础资料、背景动机和初始属性。属性由 ROLL 按钮生成，三维和六维会同时存在。
